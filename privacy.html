隱私權政策

更新日期：2026 年 10 月 30 日

本政策說明 PersonalFinance 個人本機記帳工具及此說明網站的資料處理方式。目前工具僅供個人使用與測試，不是公開的線上記帳服務。

1. 存取哪些 Google 資料

使用者自行完成 Google OAuth 2.0 授權後，工具透過 Gmail API 搜尋指定銀行寄件者與 PDF 附件，讀取符合條件郵件的寄件者、主旨、日期、郵件與附件識別資訊，以及帳單附件。連線驗證會讀取授權帳號的電子郵件地址，以確認使用的是正確信箱。

所要求的 gmail.readonly 是整個信箱的唯讀權限，不是 Google 提供的銀行專屬權限；程式使用查詢條件限制實際處理範圍。工具不要求寄送、修改或刪除郵件的權限。

2. 資料如何使用

資料僅用於使用者要求的電子帳單辨識、下載、交易解析、分類、去重、Excel 記帳與帳務核對。每日消費通知保留為待核對資料，月結交易核對後才進入測試帳本。

Google 使用者資料不作廣告、出售或模型訓練用途。PersonalFinance 對 Google API 資料的使用及傳輸遵守 Google API Services User Data Policy，包括 Limited Use 要求。

3. 資料保存在何處

原始加密 PDF、解析報告、來源索引、SQLite 同步狀態、日誌、備份及 Excel 輸出保存在使用者的 Windows 本機。OAuth Refresh Token 與 PDF 解密密碼保存在該使用者的 Windows 認證管理員；執行時所需的 Access Token 及解密密碼在記憶體中使用。

密碼及 Token 不寫入本網站、記帳程式原始碼或同步日誌。本網站的公開儲存庫只含說明頁面與樣式，不含帳單、憑證或記帳程式。

4. 資料分享與網路服務

本機工具透過 Google OAuth 及 Gmail API 取得授權與帳單，沒有將郵件、帳單或交易上傳到此說明網站、廣告服務、第三方分析服務或付費 AI API 的功能。

使用者自行把檔案分享給其他人、另行備份至雲端，或將資料交給其他工具，不是本說明網站的操作。

5. 保留、撤回與刪除

本機資料與備份會保留，直到使用者自行管理或刪除；目前工具不自動刪除原始帳單。使用者可隨時停止工具，並於 Google 帳戶的第三方連線設定撤回授權。

撤回 Google 授權不會自動刪除既有本機檔案、備份或 Windows 認證管理員項目。這些內容由使用者在自己的電腦管理；此網站沒有帳戶、資料儲存服務或遠端刪除介面。

6. 本網站的代管服務

此說明網站使用 GitHub Pages 代管。網站沒有加入分析追蹤程式、廣告、登入功能、聯絡表單或檔案上傳功能，也不要求輸入任何密碼或驗證碼。

依 GitHub 的說明，GitHub Pages 會基於安全目的記錄及保存網站訪客的 IP 位址。此類代管服務紀錄由 GitHub 處理，請參閱 GitHub Pages 資料收集說明及 GitHub 隱私聲明。

7. 聯絡與政策更新

此工具由個人維護。問題可透過 OAuth 同意畫面所列的支援電子郵件，或本網站 GitHub 儲存庫的公開議題提出。請只描述工具問題，不在公開議題提供帳單、交易明細、私人聯絡資訊、Token、密碼或驗證碼。

工具資料處理方式變更時，會同步更新本政策及頁首日期。
