工具用途

PersonalFinance 是個人使用的 Windows 本機記帳工具，目前為測試版本，僅更新測試帳本。本網站是工具介紹與政策網站，不提供線上帳戶或記帳服務，也不發布記帳程式。

資料核對

帳單格式、交易性質及商家分類可能有差異，自動解析與分類也可能出錯。使用者應核對銀行原始帳單、待確認項目及 Excel 差異，並保留必要備份。工具輸出不是銀行提供的正式帳務證明。

授權與控制

Gmail 資料存取由使用者自行同意 Google OAuth 唯讀授權。使用者可停止使用並撤回授權；資料保存及管理方式詳見 隱私權政策。

服務範圍

本工具不是銀行服務，不提供付款、轉帳、投資建議或稅務申報功能，也不代表 Google 或任何銀行。Google 與 GitHub 服務依各服務提供者的條款運作；授權有效性及網站代管可用性不保證永久不變。

支援

工具由個人維護。可透過 OAuth 同意畫面所列的支援電子郵件或 GitHub 公開議題反映工具問題；請勿張貼個人財務資料、帳單、憑證、密碼或驗證碼。
