# PersonalFinance：公開說明網站

本儲存庫只提供 PersonalFinance 個人本機記帳工具的介紹、隱私權政策與使用條款，以及頁面樣式。

- [工具介紹](https://maxhan1120.github.io/personalfinance-info/)
- [隱私權政策](https://maxhan1120.github.io/personalfinance-info/privacy.html)
- [使用條款](https://maxhan1120.github.io/personalfinance-info/terms.html)

以 GitHub Pages 從 `main` 分支根目錄發布，使用純靜態 HTML/CSS，不需要安裝套件或執行記帳程式。

不含帳單、交易資料、Excel 帳本、OAuth 憑證、PDF 密碼或記帳程式。請勿在公開議題或提交中加入這些資料。
